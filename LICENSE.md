# 🤖 FOREX AI TERMINAL

Institutional-grade AI Trading Assistant & Quant Dashboard built for Telegram Mini App.

## 🚀 Tech Stack
- **Backend:** Cloudflare Workers, D1 (SQLite), KV Storage
- **Frontend:** Next.js 14 (App Router), Tailwind CSS, Framer Motion
- **AI Engine:** DeepSeek-V4-Pro, Llama-3.3 (via Groq/Nvidia NIM)

## 📦 Deployment
1. **Backend:** `cd backend && npx wrangler deploy`
2. **Frontend:** Deploy `frontend` folder to Vercel.
